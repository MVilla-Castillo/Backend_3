# Cowork

Proyecto backend en Django. Gestión de espacios de trabajo compartido.

## Instalación

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Ejecución

```bash
python manage.py runserver
```

- Bienvenida: http://127.0.0.1:8000/
- 404: cualquier otra ruta, ej. http://127.0.0.1:8000/prueba/
